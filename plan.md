# Write Together

I want to build a simple app for my friends and i to share a writing prompt.

## Requirements

### Vision

1. There will be prompts generated by an LLM for writing, with a specified time period, and max response length.
2. Users will then write responses based on these prompts. They will submit them to be viewed by other users.

### How new prompts are piped in

1. There will be 'periods' defined by a current active prompt.
2. Periods are open-ended — there is no fixed duration.
3. The current period will be end-able by a local CLI script for now. Eventually we want it to complete automatically when certain conditions are met (all users have submitted a response.)
4. Prompts will be generated once via a one-time LLM session and stored as hard-coded static data in the codebase.

### Basic user experience

1. A user should be able to save drafts of their responses to the current prompts. They should be able to edit these at will until they submit them.
2. At the point of submission, posts will not be editable.
3. Posts can have comments from other users. To start this is just text.

### Authentication

1. Users must log in in order to post a response to the current prompt.
2. Users must be invited to join.
3. They will be invited by email.
4. Authentication uses magic link (passwordless) — users receive a one-time login link via email each session.
5. ANYONE can see the current prompt, and past prompts, and potentially also user's responses (if they flag as open to anyone), even if they are not logged in.
6. The 'open to anyone' flag should be available to any user when creating any post. It should default to true.
7. Anyone can see comments on public posts, even if not logged in.

### Technical stack

1. let's focus on a web app, since i think most people will want to write on their laptops.
2. it should still be accessible from mobile, since people may want to read from there.
3. we should use javascript, but i am open beyond that.
4. next.js seems like a good approach.
5. Supabase works for a database.
6. Vercel works for deployment.
